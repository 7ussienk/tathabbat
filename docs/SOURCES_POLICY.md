# سياسة المصادر

**القاعدة:** تُعتمد كتب علماء أهل السنة والجماعة من المذاهب الأربعة (الحنفي، المالكي، الشافعي، الحنبلي)، ودواوين السنة المعتمدة. لا تُعتمد المصادر المعاصرة ولا كتب خارج هذه القائمة لنقل الأحكام.

هذه القائمة **قابلة للتعديل من صاحب المشروع فقط**. أي كتاب جديد يُضاف إلى `data/sources/manifest.json` مع حقل `madhhab` قبل استخدامه.

## دواوين السنة
الصحيحان، السنن الأربع، موطأ مالك، مسند أحمد، سنن البيهقي.

## كتب الأحاديث المشتهرة والموضوعات ونقد الرجال (القائمة البيضاء المبدئية)
| المذهب | العالم | الكتاب |
|---|---|---|
| شافعي | السخاوي | المقاصد الحسنة |
| شافعي | ابن حجر العسقلاني | لسان الميزان، التلخيص الحبير |
| شافعي | السيوطي | اللآلئ المصنوعة، الزيادات على الموضوعات، الدرر المنتثرة |
| شافعي | ابن عراق الكناني | تنزيه الشريعة المرفوعة |
| شافعي | العجلوني | كشف الخفاء ومزيل الإلباس |
| شافعي | البيهقي | شعب الإيمان، المدخل إلى السنن |
| شافعي | النووي | شرح صحيح مسلم، الأذكار |
| شافعي | الذهبي | ميزان الاعتدال |
| حنفي | ملا علي القاري | الأسرار المرفوعة في الأخبار الموضوعة |
| حنفي | الزيلعي | نصب الراية |
| مالكي | ابن عبد البر | التمهيد، جامع بيان العلم وفضله |
| حنبلي | ابن الجوزي | الموضوعات، العلل المتناهية |
| حنبلي | ابن رجب | جامع العلوم والحكم |

## تطبيق السياسة في الكود
- البحث العميق (الشاملة/تراث) يُقيَّد بمعرّفات الكتب في الـ manifest فقط (`scope.book_ids`).
- أي نتيجة من كتاب خارج الـ manifest تُهمل ولا تُعرض حكماً.
- كلام محقق الطبعة المعاصر (الحاشية) لا يُنسب للمؤلف، ولا يُعتمد حكماً مستقلاً.
