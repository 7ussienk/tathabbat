## نسبة نص القرآن
نص القرآن الكريم المستخدم في التحقق من الآيات هو **Tanzil Quran Text (Uthmani, v1.1)** من مشروع [Tanzil](https://tanzil.net)، بترخيص Creative Commons Attribution 3.0، ويُستخدم حرفياً دون أي تعديل (الملف: `data/quran/quran-uthmani.txt`).

## إعادة بناء الفهرس المحلي (مخطط)
متون الكتب لا تُرفع إلى هذا المستودع. يُجلب النص وقت البناء (`npm run build`) عبر `scripts/fetch-books` إلى `data/local/` (مستثنى من Git)، ثم يُبنى فهرس MiniSearch ويُضمَّن في الحزمة. لإعادة البناء محلياً:
```bash
npm run fetch-books   # طلب واحد في كل مرة؛ يكتب data/local/ (خارج Git)
npm run build-index   # يقطّع المداخل ويبني data/index/ (خارج Git)
npm test              # يتضمن اختبار القبول للفهرس
```
`npm run build` ينفّذ الثلاثة ثم `next build`. إن فشل الجلب أو اختلفت بنية الكتاب يفشل البناء بوضوح ولا يُنشر فهرس ناقص.
### حدود إعادة البناء
- المسار `files.turath.io/books-v3/{id}.json` **غير موثق وقد يتغير** (وقد تعطل مسار `turath-sdk` القديم فصار يعيد 404).
- يجلب السكربت طلباً واحداً في كل مرة مع مهلة، ويخزّن في ذاكرة البناء لتقليل الطلبات، ويتحقق من شكل الملف (525 صفحة و1355 مدخلاً للمقاصد الحسنة) ويفشل البناء بوضوح إن اختلف.

## ملفات الصوت لا تُنشر
مجلد `eval/audio/` مستثنى من Git (تسجيلات شخصية والمستودع عام). تبقى النصوص المفرَّغة للحالات الصوتية في `eval/dataset.jsonl`؛ ولتشغيل التقييم الصوتي تُوضع الملفات (`T0xx.ogg`) محلياً في هذا المجلد.

## ملاحظة على «المقاصد الحسنة»
عدد المداخل **1355** لا آخر رقم: الأرقام المطبوعة تمتد إلى 1356 والرقم 406 غير موجود في الطبعة (الترقيم يقفز من 405 إلى 407). يفشل البناء إن اختلف هذا.

## حدود معروفة (مقصودة وموثقة)
- **T062 وT065 (حالات «تعارض أحكام المحدثين»):** يعيدان `scholar_text_only` (نص الإمام حرفياً بلا تصنيف آلي) لا `disputed`، لأن المعجم الثابت لا يصنّف نصَّ الإمام فيهما؛ آثرنا ألّا نُنشئ تصنيفاً آلياً من عندنا.
- **T013 (حديث صحيح):** لفظ الرسالة «أحب الأسماء إلى الله…» يختلف عن لفظ مسلم «إن أحب أسمائكم إلى الله…»، فيعيد `wording_differs` (مع المنتقى) أو `scholar_text_only` (بدونه) لا `authentic`؛ ولا نصدر «صحيح» إلا لمطابقة تامة مرتّبة للفظ.
- هذه الحالات تبقى كما هي في `eval/dataset.jsonl` وتظهر إخفاقاً في تقرير التقييم دون ضبط الاختبار عليها. وتُذكر أيضاً في صفحة «عن المنهجية».
- **الأداة قد تعرض لفظاً مختلفاً عمّا في المصدر ولا تحكم بخطئه** (`wording_differs`).
